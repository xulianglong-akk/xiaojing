# 小镜 (XiaoJing) 产品需求文档 v0.1

极简、隐私优先的 Windows 桌面 AI 助手，替代 Hermes Agent 的日常使用。

## 定位
- 一句话：**本地优先、越用越懂你的极简 AI 助手**。
- 隐私总纲见 [PRIVACY.md](../PRIVACY.md)，为最高准则。

## 三大标签页（左上角切换）
1. **聊天** — 多会话、多供应商模型、深度思考、联网搜索、计划模式
2. **Codex** — 选择工作目录的编程 agent：读写文件、执行命令（需批准）、联网搜索、计划模式
3. **机器人** — 拟人化长期 AI 伙伴：人格设定、长期记忆、单聊与多人群聊

## 记忆系统
- 每个会话独立记忆；上下文过长时自动用当前模型把旧消息压缩为「关键事实」条目，原文保留可回溯。
- 全局偏好记忆：后台提炼用户习惯（如「喜欢简洁回答」），注入每次对话 → 越用越顺手。
- 机器人拥有独立长期记忆，跨会话持续。
- 存储位置在设置中自选，随时迁移；数据为明文 JSON。

## 模型
- 云端：OpenAI / Anthropic / DeepSeek / GLM(Z.AI) / Kimi / OpenRouter / 任意 OpenAI 兼容端点。
- 本地：Ollama（安装位置、数据模型位置均可自选，本机推理不出电脑）。
- 深度思考：GLM / DeepSeek-R1 等推理模型的思考过程流式折叠显示。

## 联网搜索
- 可开关；支持 Tavily / 博查（需各自 Key）与 DuckDuckGo（免 Key）。
- 搜索结果注入当次回答并标注来源。

## 计划模式
- 聊天与 Codex 共用：开启后 AI 先给出计划，用户确认或修改后才执行。

## 非目标（v0.1）
- 不接入微信 / QQ / Telegram 等外部消息平台。
- 图标与视觉精修后续迭代。
